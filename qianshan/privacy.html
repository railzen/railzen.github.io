千山隐私政策

生效日期：2026 年 8 月 30 日
适用于 Chrome 扩展「千山新标签页」

千山是一款本地新标签页扩展，用于展示站点导航、快捷键和用户自定义配置。本扩展不向开发者服务器传输任何用户数据。开发者没有运营用于接收、存储或分析用户数据的服务器。

我们如何处理数据

当你自定义分类名称、站点名称、链接或快捷键时，这些配置会通过 Chrome 提供的 chrome.storage.sync 保存在你的设备上，并在你已登录且开启同步的 Google 账号之间同步。这些数据由 Google 的 Chrome 同步服务处理，开发者无法访问。

导入、导出配置只会在你的设备上读写本地 JSON 文件，不会上传。

我们不收集的数据

  • 姓名、邮箱、电话等个人身份信息
  • 浏览历史、当前访问的网页内容
  • 位置、Cookie、账号密码、支付信息
  • 使用统计、广告标识或崩溃上报

本扩展只申请 storage 权限，用于保存上述自定义配置。扩展内的站点链接是导航入口；点击后由浏览器直接打开对应网站，千山不会记录或回传你的点击。

如何删除数据

卸载本扩展即可停止使用本地配置。若你曾开启 Chrome 同步，还可在 Chrome 的同步设置中管理或清除同步数据。开发者无法代为删除，因为开发者接触不到这些数据。

第三方

本扩展不使用分析、广告或崩溃统计等第三方服务。Chrome 同步受 Google 隐私政策 约束。

政策变更

若数据处理方式发生变化，我们会更新本页面，并在扩展的「关于」中提示。

Qianshan Privacy Policy

Effective date: August 30, 2026
Applies to the Chrome extension “Qianshan New Tab”

Qianshan is a local new-tab extension that provides site navigation, keyboard shortcuts, and user-defined settings. This extension does not transmit any user data to the developer’s servers. The developer does not operate servers that receive, store, or analyze user data.

How we handle data

If you customize category names, site names, URLs, or shortcuts, those settings are stored on your device with Chrome’s chrome.storage.sync API and may sync across devices signed into the same Google account with Chrome sync enabled. That data is handled by Google’s Chrome sync service. The developer cannot access it.

Importing or exporting a configuration file only reads or writes a JSON file on your device. It is not uploaded.

Data we do not collect

  • Personally identifiable information such as name, email, or phone number
  • Browsing history or the content of websites you visit
  • Location, cookies, passwords, or payment information
  • Analytics, advertising identifiers, or crash reports

This extension requests only the storage permission, which is used to save the settings described above. Links on the new-tab page are navigation shortcuts; the browser opens the destination site directly. Qianshan does not log or transmit your clicks.

How to delete your data

Uninstalling the extension stops local use of your settings. If Chrome sync is enabled, you can manage or clear synced data in Chrome’s sync settings. The developer cannot delete this data on your behalf, because the developer cannot access it.

Third parties

This extension does not use third-party analytics, advertising, or crash-reporting services. Chrome sync is governed by the Google Privacy Policy.

Changes

If our data practices change, we will update this page and note the change in the extension’s About dialog.
